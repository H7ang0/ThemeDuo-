开始制作

  1. 解压制作资料，复制 theme-template/，替换需要的编号 PNG。
  2. 保留文件名与路径；不改的项目删除图片及清单条目。
  3. 把 theme.json、icons/、backgrounds/ 压成普通 ZIP 并上传主题后台。
  4. 首页卡片右侧“主题美化” → “下载主题”，授权下载后在“更改主题”切换。

制作规范与逐项说明

底栏固定 PNG：四项各两态

编号文件名固定对应
T01tab_home_normal.png底栏“首页”普通态
T02tab_home_selected.png底栏“首页”选中态
T03tab_friends_normal.png底栏“朋友”普通态
T04tab_friends_selected.png底栏“朋友”选中态
T05tab_messages_normal.png底栏“消息”普通态
T06tab_messages_selected.png底栏“消息”选中态
T07tab_me_normal.png底栏“我”普通态
T08tab_me_selected.png底栏“我”选中态

推荐每张 108×108 px 的透明 PNG。当前显示框最大 36pt，实际会按按钮可用空间缩小。每张文件只对应一个 Tab 的一个状态；普通态与选中态分别提供，缺图则保留宿主原内容。

身份来自四个 AWEBizTabBar*ItemConfig -tabBarItemViewController 返回的控制器。插件若在冷启动后才接入，会通过已声明的内层 currentTitleText，仅对“首页／朋友／消息／我”四个完整标题补绑；不按索引、未知数字枚举或模糊标题猜位置。状态读取 AWENormalModeTabBarInnerViewUIConfig.isSelected。内部文字／头像层只在替换图存在时隐藏，角标和原按钮手势保留。

首页 → 底栏设置：

  • 底栏 PNG 替换：默认开启，有当前主题且含对应 PNG 才替换。
  • 全屏视频：用于首页竖屏视频延伸到底栏下方；不代表横屏播放或强行拉伸视频比例。
  • 圆角悬浮底栏：开启时自动打开全屏视频；关闭全屏视频也会关闭悬浮。
  • 底栏圆角：12／20／27 pt，实际不超过悬浮条高度的一半。

关闭 Duo 会恢复底栏及视频布局；关闭底栏 PNG 开关只恢复图标。未知频道、无法确定状态或接口 ABI 不匹配时不套用相邻槽位。全屏布局接口不匹配时，面板阻止启用全屏与悬浮。实际手机上的视频延伸、滚动、点击和布局仍需目标抖音版本验证。

三组最容易做错的图

  • like_before.png／like_after.png 是按资源名替换的未点赞／已点赞图标；like_heart*.png／like_spread.png 属于静态点赞效果；digg_like.json 是另一路 Lottie 动画。三种资源不能互相改名代替。
  • unfavorite.png／favorite.png 是按资源名替换；favorite_off.png／favorite_on.png／favorite_spread.png 是已接入静态组件的图片属性。模板均有独立编号。
  • search.png 是命名资源回退；search_lens.png／search_clear.png 是公共搜索配置里的属性。若只放 search.png，不保证配置里的图能被替换。

theme.json 怎么写

模板已包含完整映射。下面是最小有效例子，可以把画稿任意命名，再通过键指定用途：

{
  "icons": {
    "like_heart": "icons/my-heart.png",
    "like_before": "icons/my-unliked.png",
    "like_after": "icons/my-liked.png"
  },
  "backgrounds": {
    "message": "backgrounds/message.png",
    "profile": "backgrounds/profile.png",
    "other": "backgrounds/other.png"
  }
}
  • icons 的键是 F 槽位、R 标准名，或已知的真实宿主图片名；backgrounds 使用 message、profile、other 三个键。
  • 值是主题包内相对路径。根目录必须有这个文件，不能写绝对路径、.／.. 路径段、反斜杠或 URL。清单名固定为 theme.json。
  • 图片匹配顺序：当前请求名的清单映射 → 当前请求名的文件匹配 → 标准名转换后的清单／文件匹配。精确请求名优先于模糊标准名。现有请求名同名文件命中时，不会再用标准名覆盖它。
  • 无清单也可用表中固定文件名。多个子目录存在相同文件名且无法确定唯一匹配时可能跳过；不要靠把同名图放到不同文件夹来区分页面。需要命名空间时采用 Bundles/<真实 bundle 名>/，前提是对应加载入口传入了匹配命名空间。
  • backgrounds.message 是消息 Tab／列表背景，不能写成聊天气泡。backgrounds.comment 当前没有页面消费者，不要用它制作评论气泡。
  • 删除不需要的文件及其清单条目，就能做只改部分图的主题。

尺寸、透明度与倍率

  • PNG 图标保留 alpha 通道，不要铺白底，不要把教程中的棋盘格画进 PNG。只有背景图通常需要完整底色。
  • 建议图形居中、透明边距一致。扩散层中心留空。主题功能不会自动生成气泡九宫格、拉伸边距或调整按钮位置。
  • 一套普通 name.png 最容易验证。想提供倍率，可导出 name@2x.png 与 name@3x.png，同一逻辑尺寸下 3x 像素为 2x 的 1.5 倍。
  • 例如 44pt 图标可提供 88×88 的 comment@2x.png 与 132×132 的 comment@3x.png。这是制作约定，不代表所有目标控件都固定 44pt。
  • 清单路径若直接写死某张图，就优先使用那张图，不会自动按倍率换另一张。需要自动倍率选择时删除该键的 icons 映射，使用标准文件名及倍率后缀。
  • 无显式倍率请求时，3x 设备尝试 @3x → @2x → 无后缀 → @4x；2x 设备为 @2x → @3x → 无后缀 → @4x。请求本身带倍率后缀时只匹配该后缀。
  • 当前位图解码上限 1600 万像素；ZIP 最大 64 MB，解压后总计 128 MB、单文件 16 MB、最多 4096 条目。建议背景控制在 1～3 MB，图标尽量小。
  • 使用普通 Deflate／Store ZIP，不使用加密、分卷、ZIP64、链接文件。

其他内容的支持范围

  • 私聊发送／接收气泡、输入栏整体、聊天窗口壁纸，没有在当前版本提供可承诺的固定 PNG 槽位。message_bubble.png、comment_bubble.png、bubble_background.png 不是已实现的固定命名。
  • 底部“首页／朋友／消息／我”已通过 T01～T08 固定槽位提供替换。商城、团购等其他业务 Tab 没有在这八个槽位中映射；它们保留宿主内容。底部拍摄加号仍使用 R07。
  • 网络头像、用户封面、视频画面、动态文字与未知 Asset Catalog／私有加载路径，不在这 34 项的保证范围内。
  • Assets/duo-logo.svg 是插件自身面板 Logo，不是抖音界面 PNG 槽位；放进主题包不能改插件 Logo。
  • 消息卡片的 HTML 是面板中另行导入的功能；把 message-card.html 塞进 ZIP 不会自动替换卡片。
  • 主题后台地址、授权状态与独立页面背景设置已移除。当前下载入口直接在“主题美化 → 下载主题”，本地制作的 ZIP 需上传后台上架，再通过“下载主题”获取；插件不提供本地导入。

额外 Lottie 动画（不是 PNG）

lottie/digg_like.json 可通过 "lottie":{"digg_like":"lottie/digg_like.json"} 接入点赞动画入口；其他动画依赖宿主文件名命中。插件还需开启“主题美化 → 资源与动效 → Lottie 动画替换”。当前 34 PNG 模板不含 Lottie，避免编号静态图与动画混在一起。动画画布、帧率和时长先以目标宿主资源为准，本教程不把建议值写成真实测量值。

制作交付清单

  1. 每张正式 PNG 能对应此表中的编号；没有依据的资源单独记录，不混写成已适配。
  2. 测试图编号全部替换为正式画稿；不需要的资源及映射已删。
  3. JSON 可解析、所有指向的文件存在、名称大小写一致、没有歧义同名文件。
  4. 包内只有需要的主题资源；主题 ZIP 与教程资料 ZIP 分开。
